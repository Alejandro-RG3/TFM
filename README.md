# TFM
Este repositorio contiene todo el código desarrollado en mi Trabajo de Fin de Máster (TFM).

Estructura del proyecto 

analisis/: Análisis de las variantes y correlación con fenotipo.

clinica/: Notebook para el procesamiento y limpieza de datos clínicos.

nextflow/: Pipeline de procesamiento bioinformático de FASTQ y VCF (Nextflow).

panel_genes/: Notebook para el diseño del panel de genes y el panel resultante.

entorno.yml: Especificaciones del entorno (Conda) para reproducibilidad.
